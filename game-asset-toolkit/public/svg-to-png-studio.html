    A few useful details

    Local from start to finish

    No uploaded artwork, cookies, analytics, third-party scripts, or saved file history. Self-contained SVGs work offline. Loading linked assets contacts their hosts, without cookies or a referrer; those hosts can still see your IP address.

    What renders best

    Paths, gradients, embedded images, masks, filters, and internal styles are supported by your browser’s SVG renderer. Scripts, HTML foreignObject, animation, and unsupported active elements are removed and reported. SVGs that rely on website CSS must include those rules. Embedded fonts are retained, but font support and antialiasing vary by browser; outline text when exact typography matters.

    Predictable exports

    Trimming scans alpha at up to 2048 pixels, then renders the original vector again at each target size. Tiny or faint details may need trim turned off. Output dimensions stay exact; trimming changes the artwork framing. Up to 20 SVGs, 5 MiB each, 50 MiB total input, 4096 pixels per output side, and 128 MiB per ZIP. Heavy files are queued one at a time.

    Platform bundles

    Apple includes conventional iPhone/iPad and macOS raster AppIcon catalogs with opaque PNGs; it does not create layered Icon Composer appearances. Android includes legacy icons, transparent adaptive foregrounds, and XML resources. Web includes PNG favicons, a multi-size ICO, touch/PWA icons, a maskable icon, and manifest/HTML starter files. Review generated starter metadata before publishing.
