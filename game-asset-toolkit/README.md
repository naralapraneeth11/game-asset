# Game Asset Toolkit

Clean, fast, local-first asset pipeline tool for game developers.

Built with Next.js 15 + TypeScript + Tailwind CSS + Framer Motion.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Import the repo in Vercel
3. Deploy (zero config)

Or use the Vercel CLI:

```bash
npx vercel
```

## Current status

- **UI only** — no real image processing yet
- Drop zone, scale toggles, mode switch, mock previews all interactive
- Designed to match the product blueprint (calm, professional, developer-focused)
